## 설치 및 환경 세팅

1. Android Studio 설치
1. AVD(에뮬레이터) 생성
1. ANDROID_HOME 환경 변수 설정
1. chocolatey 이용해 Node.js 및 JDK 설치
1. React Native CLI 설치

```
npx @react-native-community/cli init LearnReactNative
cd LearnReactNative
npx react-native run-android # Gradle 자동 실행
```

## 참고

JSX, Props, State, Hook, Context API 등 이미 아는 개념이 그대로 사용됩니다. 낯선 부분은 스타일링 방식(CSS 대신 StyleSheet)과 네이티브 컴포넌트(div 대신 View, p 대신 Text) 정도입니다.
지금 세팅된 상태로 바로 프로젝트 만들고 시작하는 걸 추천합니다!

### 반드시 보충이 필요한 챕터

- 1장 - 작업 환경 준비하기
  이미 함께 진행 중이지만, 책의 설치 방법과 현재 환경이 많이 달라져 있습니다. 특히 HAXM 대신 WHPX를 써야 하는 점, 프로젝트 생성 명령어 옵션 등은 제가 보충해드려야 합니다.
- 4장 - AsyncStorage
  책에서는 @react-native-async-storage/async-storage 설치 방법이 구버전 기준입니다. 현재 설치 방법과 자동 링킹 방식이 다를 수 있어서 오류가 날 가능성이 있습니다.
- 5장 - 리액트 내비게이션
  책은 react-navigation v6 초기 기준인데, 현재는 v7이 출시되었습니다. API 자체는 크게 안 바뀌었지만, 설치 명령어와 일부 옵션이 달라졌습니다. 특히 @react-navigation/native-stack 설정 부분을 주의해야 합니다.
- 8~9장 - Firebase
  이 챕터가 가장 많이 달라졌습니다. Firebase SDK 자체가 v8→v9→v10으로 대폭 업그레이드되면서 모듈형 API로 완전히 바뀌었습니다. 책의 코드를 그대로 따라 하면 대부분 작동하지 않아요. 이 챕터는 제가 적극적으로 보충해드려야 합니다.
- 13장 - 상태 관리 (Redux / Recoil)
  Redux Toolkit은 책 내용과 큰 차이 없지만, Recoil은 현재 공식 지원이 불투명합니다(Meta가 개발을 사실상 중단). 입문 단계라면 Recoil 대신 Zustand를 함께 알려드리는 게 좋습니다.
- 14장 - Strapi
  Strapi가 v3→v4→v5로 업그레이드되며 API 구조와 설정 방법이 크게 바뀌었습니다. 책의 내용대로 하면 거의 작동하지 않으니 이 챕터는 제가 현재 버전 기준으로 보충해드려야 합니다.
